# FeedShift Figma Page Build — 05 States v1

## Page Name

`05 States`

## Goal

Build empty, loading, and error states using FeedShift's system language.

## Source

`figma-assembly-states-v1.md`

## Frame Groups

```text
Empty States
Loading States
Error States
```

## Empty States

Build:

```text
Empty / No Snapshot
Empty / No History
Empty / No Permission
```

Structure:

```text
Atmosphere Layer
Empty Halo
Empty Statement
Gentle Next Step
```

Rules:

- No sad icons.
- No illustrations.
- No dashboard placeholders.
- No marketing copy.

## Loading States

Build:

```text
Loading / Reading Content
Loading / Generating Snapshot
```

Structure:

```text
Atmosphere Layer
Developing Halo
One-line status
```

Rules:

- No spinner.
- No skeleton cards.
- No progress percent.
- No AI thinking copy.

Motion note:

```text
Halo breathing: 1800ms loop
Air shift: 3600ms loop
```

## Error States

Build:

```text
Error / Permission Denied
Error / No Text Detected
Error / Read Failed
```

Structure:

```text
Atmosphere Layer
Soft Error Statement
Recovery Action
Optional Secondary Action
```

Rules:

- No red alert.
- No technical stack text.
- No blame language.
- No modal-first error.
